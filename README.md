# Retail Sales Analysis SQL Project

## Project Overview
This project is designed to demonstrate SQL skills and techniques typically used by data analysts to explore, clean, and analyze retail sales data. The project involves setting up a retail sales database, performing data cleaning, executing exploratory data analysis (EDA), and answering specific business questions through complex SQL queries.

## Project Structure
- **Database Setup:** Creation of the retail_sales table with constraints and primary keys.
- **Data Cleaning:** Checking and removing NULL values to ensure data integrity.
- **Data Exploration:** Calculating total sales, unique customers, and category distributions.
- **Business Analysis:** Solving real-world retail business problems using advanced SQL clauses (Aggregations, GROUP BY, HAVING, Window Functions, CTE, and CASE statements).

## Key Business Problems Solved
1. Retrieve all columns for sales made on a specific date (2022-11-05).
2. Find transactions where the category is 'Clothing' and quantity sold is greater than or equal to 4 in Nov-2022.
3. Calculate total sales and total orders for each category.
4. Find the average age of customers who purchased from the 'Beauty' category.
5. Find all transactions where total sales are greater than 1000.
6. Find total transactions made by each gender in each category.
7. Calculate average sales for each month and find the best-selling month in each year.
8. Find the top 5 customers based on highest total sales.
9. Find the number of unique customers who purchased items from each category.
10. Analyze sales shifts (Morning, Afternoon, Evening) and count total orders per shift.

## Skills Demonstrated
* Advanced SQL Queries (JOIN, GROUP BY, ORDER BY)
* Window Functions (RANK(), PARTITION BY)
* Common Table Expressions (CTE)
* Data Cleaning & Validation
